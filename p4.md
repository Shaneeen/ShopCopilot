```

scripts/create_dev_split.py             # deterministic 160/40 dev/holdout split
neeshops/research/README.md
```

**Do NOT edit:** `evaluator/**` (never — `git diff upstream/main -- evaluator/` must stay empty), `neeshops/conversation/**` (P1), `neeshops/retrieval/**` (P2), `neeshops/ranking/**` (P3) — you *run experiments over their config values*, never edit their code (`TEAM_WORKSTREAMS.md:252`). Do not edit `data/public_set.jsonl` labels.

Provides per `INTEGRATION_CONTRACTS.md:98`:
```python
ExperimentRunner(evaluate_fn: (strategy:dict, dataset_path:str) -> dict[str,float])
# evaluate_fn returns dict containing "technical_score" (aliased from evaluator's recommended_technical_score)
# run() -> {experiment_id, name, hypothesis, parameters, metrics, baseline_metrics, accepted:bool, timestamp}
# metrics includes evaluator's full dict: hit_rate, mrr, mttc, efficiency, technical_score, scenario_metrics, reported_token_usage
# Experiment.__post_init__ raises ValueError if param not in SAFE_PARAMETERS — fails before any eval
```

`neeshops/research/` never imports `evaluator/` directly — coupling only in `scripts/*` so you can develop without catalog.
