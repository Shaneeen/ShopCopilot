## 0. Problem Statement (TikTok TechJam 2026 Track 4)

> If this file is missing `problem_statements.md` / `docs/competition_specification.md`, ask user to provide the TikTok TechJam 2026 Track 4 statement. The summary below is from `problem_statements.md:4` + `docs/neeshops/TRACK4_REQUIREMENTS.md`.

**Shopping Copilot: AI Conversational Search and Recommendations** — Build a headless agent (max 10 turns, `top_k=10`) that finds a hidden Amazon target (50k `Clothing_Shoes_and_Jewelry` catalog, read-only) across 4 pillars:

- **I. Core Architecture — Intent Routing & Hybrid Pipeline:** dual-track `Buying` (high-precision filter track, hard constraints) vs `Browsing` (diverse dense retrieval, cross-category)
- **II. Dialog Strategy — Multi-Turn Scenario Evolution:** dynamic state machine handling `Information Accumulation` (incremental slots) + abrupt `Intent Override` (slot erasure/rewriting) + `Over-Generality` cutoff → proactive `ask_attribute` clarification
- **III. Self-Evolution — Dynamic Context Programming:** distillation of short-term state + long-term `user_profile` (`purchase_frequency, average_prior_rating, rating_style, preference_tags, summary`) via runtime orchestration
- **IV. Evaluation Matrix:** `Hit Rate@10` (coverage), `MRR` (precision), `MTTC` (Mean Turns to Conversion, miss=11), `Efficiency=(11-MTTC)/10`, `TechnicalScore=0.5*HR+0.3*MRR+0.2*Eff` — baseline weak BM25 `0.125/0.068/9.81/0.10671` (`docs/baseline_results.json`)

Constraints: no external vector DB (in-memory only), no catalog mutation, no full LLM fine-tuning, no UI required, secrets via `.env`.
