Conversation & Dialogue Intelligence

neeshops/conversation/

Handles user memory across all 10 turns. Crucially implements Intent Override semantics: if a user later says *"Actually, ignore blue, I want black"*, the state replaces the constraint rather than merging it.

constraints.py

Extracts budget ($), color, brand, style, and handles "don't care / no preference" tokens.

intent.py

Detects Buying vs. Browsing intent using sticky route detection to prevent oscillations.

clarification.py

Manages question budget (max 2/session) and triggers questions when candidate pool is too broad.

Hybrid Retrieval & Filtering

neeshops/retrieval/

Combines sparse keyword index (SQLite FTS5 full-text matching with BM25 ranking) and dense semantic vectors. Merges candidate pools using min-max score normalization.

Adaptive Route Weighting

Weightings adjust dynamically based on user intent state:

Buying Route: 70% BM25 / 30% Semantic
Browsing Route: 30% BM25 / 70% Semantic
Fail-Open Metadata Filters

Applies hard price/budget & category filters, plus soft text-containment checks for attributes without dedicated schema fields (color, material, brand). Never drops products due to sparse catalog metadata.

Ranking & Personalization

neeshops/ranking/ & personalization/

Reranks top candidate items and attaches explainable human-readable justification reasons for recommendations.

Soft Personalization Formula:
FinalScore = RetrievalScore * (1 - PersonalizationWeight) + ProfileBoost * PersonalizationWeight

*ProfileBoost calculates keyword overlap against the user's historical preference_tags ("comfort", "durability", "breathable"). Crucially, personalization is a soft nudge and never overrides explicit conversation constraints.

Research Agent & Optimization
